# Project OPTIMUS 🤖

An advanced, voice-activated Android assistant engineered for hands-free control, low-latency wake-word detection, and real-time LLM response streaming.

> **Status:** 🚧 Under Active Development 🚧

## 🌟 Key Features
- **Custom Wake-Word Engine:** Passive background listening tuned for low latency and minimal false positives.
- **Asynchronous LLM Streaming:** Real-time speech-to-text and AI response handling built on Kotlin Coroutines and Flow.
- **Hands-Free Control:** Multimodal interaction designed for seamless daily utility.

## 🛠️ Tech Stack
- **Language:** Kotlin
- **Architecture:** Clean Architecture / MVVM
- **Concurrency:** Kotlin Coroutines, StateFlow / SharedFlow
- **Platform:** Android SDK
